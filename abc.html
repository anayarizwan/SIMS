### 🎨 5-Color Cheat Sheet | Color | Hex | Use it for | | -------------------- | --------- | ------------------------------------------------ | | 🌑 **Midnight Navy** | `#0F172A` | Sidebar, Navbar, Headings, Footer | | 🟣 **Royal Indigo** | `#6366F1` | Primary Buttons, Active Links, Icons, Highlights | | 🩶 **Cool Gray** | `#F1F5F9` | Main Background, Dashboard Background | | 🤍 **White** | `#FFFFFF` | Cards, Forms, Tables, Modals, Login Box | | 🔘 **Slate** | `#475569` | Paragraphs, Labels, Secondary Text, Muted Icons | ### Easy Rule **Navy → Structure** **Indigo → Action** **Gray → Background** **White → Content** **Slate → Secondary Information**
